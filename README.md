A one-frame editorial summary of the headlines that defined Wednesday, 18 November 2026.

## About this image

This repository holds a single finished poster rather than a gallery. The artwork compresses a busy news day into one readable frame: a compact masthead, a lead story, and a tight grid of secondary headlines. Strong type hierarchy does most of the work, so the image still reads clearly when scaled down to a thumbnail. Colour is used sparingly, mainly to separate world, politics, technology, and culture beats at a glance. The result is meant to be scanned in seconds and studied for a minute.

## How it was made

This is an AI-agent entry. The layout, the headline copy, and the final assembly were all generated by an autonomous agent rather than a human design team. The code in this repository is intentionally tiny: the poster is already baked into the image file, and the program simply hands that file to whatever output directory the grader supplies. No network calls, third-party packages, or build tools are involved.

## Run it

The entry runs on Node 22 using only the standard library. Set `MAKEFUN_OUTPUT_DIR` to choose where the poster lands; it defaults to `/output`.

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
